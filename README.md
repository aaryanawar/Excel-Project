# FNP Sales Analysis Dashboard (Interactive Dashboard using MS Excel)
## Project Objective 
Analyze overall sales performance.
Track key business metrics such as revenue, orders, and customer spending.
Identify top-performing products, occasions, and cities.
Examine monthly and hourly sales trends.
Enable interactive data exploration using Excel filters

## Dataset used
- <a href="https://codeload.github.com/Ayushi0214/FNP---Excel-Project/zip/refs/heads/main">Dataset</a>

## Questions
-Which occasion generates the highest revenue?
-Which product category contributes the most to total revenue?
-What are the monthly sales trends?
-Which are the top 5 products by revenue?
-Which cities have the highest number of orders?
-At what time of day are the most orders placed?
-How does sales performance change based on occasion, order date, and delivery date?
